Block-Level vs Inline Elements

1. Block-Level Elements

Block-level elements start on a new line take up the full width.

This is a P element

2. Inline Elements

Inline elements stay on the same line and take up only the space they need.

3. Main Differences

Block-Level Inline
Starts on a new line Stays on the same line
Usually takes full available width Takes only the required width
Examples: div, p, h1 Examples: span, a, strong
